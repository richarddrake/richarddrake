# AI 测试平台演示需求

## 背景

测试团队希望把需求材料、接口契约和执行结果串起来，减少人工编写接口回归用例的成本。

## 核心流程

1. 用户上传 PRD、流程图、界面截图或 OpenAPI 文档。
2. 系统生成结构化测试用例，并给出质量评分和覆盖率矩阵。
3. 对带有接口配置的用例，用户可以在前端直接执行。
4. 执行失败时，系统给出失败分类、证据和下一步排查建议。
5. 所有生成结果可导出 Excel，启用 MySQL 后保存历史记录。

## 重点测试点

- 主流程：导入材料后生成用例成功。
- 接口契约：OpenAPI 路径、方法、参数、请求体和响应 Schema 解析正确。
- 异常场景：缺少必填参数、非法参数、服务不可达、状态码不匹配。
- 权限场景：接口需要鉴权时，无 Token 请求应被拒绝。
- 边界场景：字段长度、数值范围、limit 最大最小值。
- 数据一致性：生成历史、Excel 下载地址和 MySQL 记录一致。
- 可执行性：用例包含 method、url、headers、body、assertions 后可一键执行。
