# 多源材料输入说明

系统已从“只支持图片”扩展为“多源材料输入”。你可以把需求、流程、字段、规则和外部文档线索一起提供给系统，让模型生成更完整的测试用例。

## 支持的输入类型

| 类型 | 格式 | 处理方式 |
| --- | --- | --- |
| 图片 | PNG、JPG、JPEG、WebP、GIF、BMP、SVG | 作为视觉材料发送给多模态模型 |
| Excel 表格 | XLSX、XLSM、XLS | 抽取工作表文本、字段和行数据 |
| CSV/TSV | CSV、TSV | 抽取表头和行数据 |
| Word 文档 | DOCX | 抽取段落和表格文本 |
| PDF | PDF | 抽取前若干页文本 |
| 文本材料 | TXT、MD、JSON、YAML、LOG、FEATURE、HTML | 直接读取文本内容 |
| 外部链接 | 飞书文档、知识库、PRD、接口文档、网页链接 | 作为来源线索进入提示词 |

单个文件建议不超过 20MB，一次最多上传 12 个材料文件。

## 推荐使用方式

### 思维导图或流程图

直接上传图片即可，适合识别流程分支、状态流转、主流程和异常流程。

### Excel 或 CSV

上传包含字段、规则、数据字典或业务清单的表格，适合生成字段校验、枚举值、边界值、数据一致性、导入导出类测试。

### Word 或 PDF

上传 PRD、需求说明、接口说明或验收标准，适合提取业务规则、权限规则、审批流、状态机和异常处理。

### 飞书文档

如果是公开可读链接，可以粘贴到“外部文档 / 飞书链接”输入框。

如果是公司内部私有文档，系统无法直接读取你的飞书账号内容。推荐使用以下方式之一：

- 从飞书导出为 Word、PDF 或 Excel 后上传
- 复制关键章节到“上下文背景”
- 粘贴飞书链接，同时上传对应导出文件

这样生成的测试用例会把链接作为来源线索，把导出文件或粘贴内容作为真实可分析材料。

## 后端解析规则

后端会把文件分成两类：

- 图片：发送给支持图片输入的多模态模型
- 可解析文件：先抽取文本，再和用户要求、上下文、外部链接一起发送给模型

不可解析或解析失败的文件不会中断整个流程，系统会把文件名和解析状态作为来源线索传给模型。

## 依赖说明

多源材料解析依赖这些 Python 包：

```text
openpyxl      解析 XLSX/XLSM
xlrd          解析 XLS
python-docx   解析 DOCX
pypdf         解析 PDF
```

安装方式：

```powershell
pip install -r requirements.txt
```

## 使用建议

为了让生成质量更高，推荐组合输入：

```text
流程图图片 + PRD 文档 + 字段 Excel + 用户要求 + 飞书链接
```

用户要求可以写得更明确，例如：

```text
重点覆盖审批流、权限、异常回退、重复提交、导入导出、字段边界值和移动端兼容性。
```
